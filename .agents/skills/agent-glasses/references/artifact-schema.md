# Artifact schema

## `config.json`

Required keys:

```json
{
  "audit_id": "YYYY-MM-DD-business-slug-v1",
  "protocol_version": "agent-glasses-v1",
  "target_url": "https://example.com/",
  "name": "Example",
  "social_handle": {"platform": "Instagram", "value": "@example"},
  "city": "City",
  "province": "Province",
  "country": "Country",
  "local_language": {"code": "id", "name": "Indonesian"},
  "templates": {
    "en_base": "What do you know about {identity}?",
    "local_base": "Apa yang kamu ketahui tentang {identity}?",
    "local_location": "Apa yang kamu ketahui tentang {url} di {location}?"
  }
}
```

Use `null` for unavailable optional signals. `name` and `target_url` are
required after reference extraction.

## `plan.json`

Generated by `scripts/build_plan.py`. Every execution row contains:

- `session_id`: stable unique identifier
- `round`: 1 through 7
- `execution_order`: global one-based order
- `prompt_id`: stable ID for unique prompt text
- `prompt`: exact text to submit
- `labels`: one or more conceptual matrix cells represented by this prompt
- `language`, `identity_signals`, and optional `location_level`

## `ledger.jsonl`

Append one JSON object per browser attempt:

```json
{
  "session_id": "S0001",
  "attempt": 1,
  "accepted": true,
  "started_at": "2026-09-04T12:34:56+08:00",
  "completed_at": "2026-09-04T12:35:12+08:00",
  "prompt": "What do you know about https://example.com/?",
  "answer": "Complete first answer...",
  "logged_out_verified": true,
  "incognito_verified": true,
  "single_turn_verified": true,
  "generation_complete": true,
  "window_closed": true,
  "autonomous_browsing": "observed",
  "citation_labels": ["example.com"],
  "error": null
}
```

Allowed `autonomous_browsing` values are `observed`, `not_observed`, and
`unknown`. Failed attempts use `accepted: false`, preserve the error, and retain
whatever evidence was captured.

## `audit.json`

Generated by `scripts/audit_ledger.py`. It validates plan coverage, exact prompt
matching, successful-attempt uniqueness, ordering, isolation, login state,
single-turn state, answer presence, and window closure.

## `reference.json` and `report.md`

`reference.json` preserves website-derived claims and provenance. `report.md`
contains semantic evaluation and must link back to the machine-readable files.
Never discard raw answers after generating the report.

## `signals.json` and `analysis.json`

`signals.json` defines case-insensitive regular expressions for literal field
coverage plus the signal groups used by declared entity-resolution and
actionability heuristics. `scripts/summarize_ledger.py` generates
`analysis.json`. These deterministic counts aid review but never replace a
semantic assessment of ambiguity, negation, or conflicting claims.
